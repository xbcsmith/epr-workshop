# Event Driven Agents with EPR

In this session, we will explore how to build event-driven agents. We will do a
generic demo and one using the Event Provenance Registry (EPR) as a central
component.

## Overview

Event-driven agents are designed to react to events in real-time, allowing them
to perform actions based on specific triggers. By leveraging the Event
Provenance Registry (EPR), we can create agents that not only respond to events
but also maintain a record of their actions and the events they have processed.

## Generic Event-Driven Agent Demo

In this demo, we will build a simple event-driven agent that listens for
specific events and performs actions based on those events. The agent will be
designed to react to events such as "new user registration" or "order placed"
and will log its actions accordingly.

## EPR-Integrated Event-Driven Agent Demo

In this demo, we will enhance our event-driven agent by integrating it with the
Event Provenance Registry (EPR). The agent will not only react to events but
also log its actions and the events it processes in EPR. This allows us to
maintain a comprehensive record of the agent's activities and the events it has
interacted with.

## Key Learning Objectives

- Understand the concept of event-driven agents and their applications.
- Learn how to integrate EPR into an event-driven agent architecture.
- Build a simple event-driven agent that reacts to events and logs its actions
  in EPR.
